### Summary

The functional design covers all 36 acceptance criteria and agrees with the C1 and C11 contract, but four security and correctness gaps need fixing before code generation: throttling responses that undo the anti-enumeration decision (R-01), a logout that can leave a live session after a refresh race (R-02), a change-password session rule that depends on a cookie that may never arrive (R-03), and the reuse-detection side effect of a lost refresh response (R-04). The Minor findings are clarifications that would otherwise surprise code generation.
